# Security Policy (template)
Purpose: tell the Codex coding agent how to use `templates/common/SECURITY.md` as a runtime-pack surface and when to stop browsing.

## Reporting a vulnerability
- Email: security@example.com (replace)
- Alternatively: file a private security advisory (GitHub Security Advisories) if enabled.
- Please include:
  - affected version/commit
  - reproduction steps
  - impact assessment
  - any suggested mitigations
  - whether exploit is public or embargoed

## Response expectations (example)
- Acknowledge within 2 business days
- Provide a status update within 7 days
- Coordinate disclosure timeline with reporter

## Supported versions
Define which branches/tags receive security fixes.

## Notes
- Do not file public issues for undisclosed vulnerabilities.
- Never include secrets in reports (tokens, customer data). Use redaction/synthetic repros.
