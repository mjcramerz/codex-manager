## When NOT to use pack hubs
- If the task is about a project codebase, route to core or domain entrypoints first.
- Use pack hubs only when you need pack scaffolds, templates, or internal maintenance guidance.
- If you are unsure, go to `$CODEX_HOME/index/core/overview.md` and pick a workflow entrypoint.
