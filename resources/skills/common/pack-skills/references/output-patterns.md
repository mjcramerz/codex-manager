# Output patterns
Reusable output structures for skill responses.

## Plan output (default)
```
# Plan

<1–3 sentences on intent and scope.>

## Requirements
- ...

## Scope
- In:
- Out:

## Files and entry points
- ...

## Action items
[ ] ...

## Testing and validation
- ...

## Risks and edge cases
- ...

## Open questions
- ...
```

## Triage summary
```
## Summary
- What changed and why
- Files touched

## Validation
- Commands run + results

## Risks / Follow-ups
- Known risks or TODOs
```

## Checklist output
```
## Checklist
- [ ] ...
- [ ] ...
```

## Linking guidance
- Related lists may place prompts first for discoverability; routing order still applies.
- Place skills last.
- Use backticked relative paths for navigation.
