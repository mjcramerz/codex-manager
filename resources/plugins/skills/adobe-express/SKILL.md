# Adobe Express

## Use this skill when
- the user needs fast template-driven design for social posts, flyers, or invitations
- a UI-first workflow is preferred for layout, branding, and multi-format exports
- outputs need explicit platform sizes and quick iteration cycles

## Workflow
1) Confirm target channels, dimensions, copy constraints, and brand requirements.
2) Use the `adobe-express` app to build or refine template-based creative assets.
3) Capture exported filenames, variants, and format mappings per target channel.
4) Hand off to local docs/media skills when downstream packaging, publishing, or additional transformations are required.

## Outputs
- Adobe Express design workflow with explicit channel and size targets
- Export checklist covering filenames, dimensions, and usage notes
