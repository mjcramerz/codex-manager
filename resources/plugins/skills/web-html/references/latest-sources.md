## High-priority guidance deltas
- Use WCAG 2.2 checks by default, especially focus appearance and target-size requirements.
- Prefer native semantic controls before custom ARIA widgets.
- Treat user-supplied markup as untrusted and sanitize before rendering.

## Skill purpose
Build semantic, accessible HTML pages and templates with clear contracts and deterministic quality checks.
