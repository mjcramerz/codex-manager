# Google Calendar

Use this plugin when the task involves calendar availability, scheduling, or event updates tied to Google Calendar.

- Prefer explicit dates, times, and attendee details.
- Confirm timezone assumptions before changing events.
- Keep scheduling operations deterministic and easy to audit.
