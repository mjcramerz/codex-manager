# Obsidian TOC Examples

## Update TOC for a note
```
python scripts/generate_toc.py --file notes/engineering/overview.md --max-depth 2
```

## Preview TOC
```
python scripts/generate_toc.py --file notes/engineering/overview.md --dry-run
```
