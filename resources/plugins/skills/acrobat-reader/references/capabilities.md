# Acrobat Reader capabilities

## Best-fit tasks
- Review PDFs and summarize comments or required edits.
- Combine multiple PDFs into a single packet with a requested page order.
- Reorder, rotate, split, or extract pages while keeping the source set intact.
- Compare two PDF versions and summarize meaningful changes.
- Export a polished PDF into another requested format when Acrobat is the preferred workflow.

## Inputs to collect
- source filenames and desired output filename
- page ordering rules and section boundaries
- whether bookmarks, comments, attachments, or annotations must be preserved
- whether the user needs an archival copy, a review copy, or an editable export

## Questions to resolve early
- Is the goal review-only, restructuring, comparison, or export?
- Should comments remain editable or be resolved before handoff?
- Does the final file need bookmarks, page labels, or a flattened copy?

## Handoff checklist
- exact output filenames
- page count and page order
- note any remaining manual sign-off or content review
