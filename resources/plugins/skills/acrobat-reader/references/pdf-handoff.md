# PDF handoff checklist

Before handing off Acrobat work:
- record the final PDF filename and intended destination
- confirm page order, rotation, and deleted/inserted pages
- summarize annotation intent and unresolved comments
- note whether the next step is review, signature, export, or code-based rework

If the PDF must be regenerated or repaired programmatically, hand off to:
- `document-artifacts:pdf` for PDF rendering or extraction work
- `document-artifacts:doc` for DOCX-origin layout workflows
