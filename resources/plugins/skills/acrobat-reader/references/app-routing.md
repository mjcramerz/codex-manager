# Acrobat app routing

Use the `adobe-acrobat` app when the task is primarily interactive PDF work:
- opening and reviewing existing PDFs
- rotating, reordering, merging, splitting, or exporting pages
- adding comments, highlights, and markup

Prefer local `document-artifacts` skills when the task is code-driven:
- generating a brand-new PDF from structured data
- repairing layout defects programmatically
- extracting text or tables in bulk

Handoff checklist:
- source filenames
- output filename
- page count before/after
- annotations or comments added
- unresolved manual follow-up
