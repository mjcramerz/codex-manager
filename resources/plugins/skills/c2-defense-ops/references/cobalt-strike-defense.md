# Cobalt Strike defense operations

## Objective
Improve detection and containment against beacon-like C2 activity.

## Defensive focus
- callback cadence/jitter anomaly detection
- TLS/HTTP profile drift monitoring
- redirector and ingress hardening validation
- SOC response quality and containment speed

## Evidence expectations
- network traces and log extracts
- detection rule matches and misses
- containment timeline with owner notes
